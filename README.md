## 📌 Sobre o projeto

Site desenvolvido para a **Elo Forte Team**, academia de Jiu-Jitsu Brasileiro localizada em Vila Caiçara, Praia Grande — SP. Não é um projeto conceitual: é o site que a academia usa hoje para se apresentar, mostrar horários, endereço e captar alunos.

A página funciona como a porta de entrada de um ecossistema maior — os links de **Cadastro** e **Login** direcionam para a área do aluno, onde o praticante acompanha graduação e avisos da equipe, integrando a camada institucional (marketing e conversão) com o sistema de gestão da academia.

## ✨ Funcionalidades

- **Hero de impacto** com identidade visual da academia (logo, imagem de tatame, chamada para aula experimental)
- **Seção "Por que escolher o Jiu-Jitsu?"** — 6 cards de benefícios (autoconfiança, condicionamento, defesa pessoal, disciplina, comunidade, superação)
- **Metodologia em 4 pilares** — do fundamento ao sparring guiado, explicando a progressão pedagógica das aulas
- **Galeria da academia** com carrossel de fotos do espaço e dos treinos
- **Grade de horários** dinâmica (manhã e noite, segunda a sexta)
- **Mapa incorporado** com o endereço exato via Google Maps
- **CTA direto para WhatsApp** para agendamento de aula experimental — pensado para conversão real, não só estética
- **Área do aluno** (login/cadastro) integrada a um domínio próprio (`eloforteteam.com.br`)
- **Totalmente responsivo**, com foco em performance de carregamento de imagens

## 💡 Por que esse projeto importa

Esse não é um clone de layout ou um template genérico de "landing page fitness". É um projeto freelance real, com cliente real, prazo real e um objetivo de negócio claro: transformar visitante em aluno matriculado. Envolveu decisões de UX pensadas para o público da academia (linguagem direta, prova social visual, atrito mínimo até o WhatsApp) e integração com um sistema de autenticação externo já em produção.
